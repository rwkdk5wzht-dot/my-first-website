# 项目工作台 / プロジェクト管理

一个使用 HTML、CSS 和原生 JavaScript 构建的中日双语个人项目管理网站。内置三个虚拟项目，不包含真实公司信息。无需安装依赖。

中国語・日本語を切り替えられる個人向けプロジェクト管理サイトです。サンプルは架空のデータで、依存パッケージのインストールは不要です。

## 使用方法 / 使い方

打开 `index.html` 即可查看。为了稳定验证浏览器本地存储，建议从同一个 HTTP 地址使用网站。如果环境已安装 Python，可在仓库根目录运行 `python3 -m http.server 8000`，然后访问 `http://localhost:8000`。

- 右上角切换中文或日文。内置示例随语言切换，自行输入的文本按原样显示。
- 在「项目进度」新增、编辑或删除项目。进度为 0–100，截止日期可选。编辑器中的待办和风险每行一项。
- 在「待办事项」标记完成或重新打开，在「风险管理」标记解决或重新打开。在「更新记录」查看项目操作历史。
- 每个模块都可按关键字、状态、优先级组合筛选。待办与风险采用所属项目的优先级，更新记录保留操作当时的优先级。
- 项目和语言设置保存到浏览器的 `localStorage`。同一浏览器和站点地址刷新后可继续使用。清除站点数据会恢复初始示例，内容不会随设备同步。

右上の言語ボタンで表示を切り替えます。進捗管理からプロジェクトを追加・編集・削除できます。タスクとリスクは編集画面に 1 行ずつ入力し、各モジュールで状態を更新します。検索・状態・優先度は組み合わせて使用できます。入力内容と表示言語は同じブラウザーのサイトデータに保存されます。

## GitHub Pages 部署

审核合并后，在仓库的 **Settings → Pages** 中将 **Source** 设为 **Deploy from a branch**，选择 `main` 和 `/(root)` 后保存。页面使用相对路径，也适用于仓库名作为子路径的站点。当前仓库为私有仓库，能否启用 Pages 取决于账户套餐和仓库设置。启用前请确认目标站点的访问权限。

## 后续维护

- `index.html` 管理页面结构、表单和基础可访问性标签。
- `styles.css` 管理颜色、布局和移动端断点。
- `app.js` 中的 `copy` 管理中日文案，`sample` 管理首次访问的示例数据。修改示例后可用无痕窗口验证首次加载。
- 如需修改数据结构，请为 `personal-project-desk-v1` 下的现有数据提供迁移。修改后请检查四个模块、组合筛选、语言切换、项目增删改、刷新后的数据保留，以及窄屏显示。
